# 前端架构文档

## 1. 架构概述

本项目是**在线医疗问诊平台**的前端应用，基于 **Vue 3 + TypeScript + Vite** 技术栈构建。采用**单页应用 (SPA)** 架构，通过 REST API 与后端微服务通信。

### 1.1 架构目标

| 目标 | 说明 |
|------|------|
| **组件化** | 可复用组件，提高开发效率 |
| **类型安全** | TypeScript 提供编译时类型检查 |
| **响应式** | 数据驱动视图，自动更新 |
| **高性能** | Vite 构建工具，快速冷启动和热更新 |
| **易维护** | 清晰的分层架构，便于迭代 |

```
═══════════════════════════════════════════════════════════════════════════════

   ┌─────────────────────────────────────────────────────────────────────────┐
   │                                                                         │
   │   User Action    ──►    Update State    ──►    Re-render View          │
   │                                                                         │
   │   (用户点击按钮)       (Store 修改数据)        (Vue 响应式更新)          │

   ❌ View 直接读取 Data 文件
```

## 4. 核心模块详解

### 4.1 路由模块 (Router)

```typescript
// src/router/index.ts

// 路由配置结构
const routes = [
  {
    path: '/',                    // 路由路径
    name: 'Home',                 // 路由名称
    component: Home,              // 页面组件
    meta: { title: '在线问诊平台' } // 元数据
  },
  {
    path: '/doctor/room/:username',  // 动态路由
    name: 'DoctorRoom',
    component: DoctorRoom,
    props: true,                  // 将路由参数作为 props
    meta: { requiresAuth: true }  // 需要登录
  }
]

// 路由守卫 (未来扩展)
router.beforeEach((to, from, next) => {
  if (to.meta.requiresAuth && !store.isAuthenticated) {
    next('/doctor/login')
  } else {
    next()
  }
})
```

```typescript
const pendingQuestions = computed(() =>
```

```
  • feat     - 新功能
  • fix      - 修复
  • docs     - 文档
  • style    - 格式 (不影响代码运行)
  • refactor - 重构
  • test     - 测试
  • chore    - 构建/工具

示例:
  feat(consultation): 添加患者身份验证功能
  fix(store): 修复问题状态更新不生效的 bug
  docs(readme): 更新项目说明文档
```

### 10.2 Nginx 配置示例

```nginx
# nginx.conf

server {
    listen 80;
    server_name qa.example.com;
    
    # 静态资源
    location / {
        root /var/www/qa-web/dist;
        index index.html;
        try_files $uri $uri/ /index.html;  # SPA 路由支持
    }
    
    # API 代理
    location /api/ {
        proxy_pass http://backend-server:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    
    # 缓存静态资源
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```
