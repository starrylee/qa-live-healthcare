# FT-002-US-01 倒序查看本人全部问诊记录

## 用户故事

作为一个 已通过 FT-001 身份验证的患者，
我想要 以倒序列表查看本人全部历史问诊记录（每条含咨询医生姓名、状态标签、内容摘要、提交时间），
以便 快速掌握自己的问诊进展与整体情况。

## 验收标准（AC）

**AC-1: 倒序列表渲染**
- **Given** 患者已通过 FT-001 验证进入门户问诊记录区块，且历史问诊数据可获取（FT-001 接口就绪时取真实数据，未就绪时以 mock 兜底）
- **When** 系统拉取该患者全部问诊记录并渲染
- **Then** 列表按提交时间倒序呈现，每条记录展示咨询医生姓名、状态标签、问题内容摘要与提交时间

**AC-2: 状态标签区分**
- **Given** 列表已渲染
- **When** 系统展示每条记录的状态
- **Then** 以标签清晰区分「待回答」与「已回答」两种状态，不展示「已关闭(closed)」

**AC-3: 内容摘要截断**
- **Given** 列表中存在问题内容较长的记录
- **When** 系统以折叠态展示问题内容
- **Then** 内容按字符数截断约 50 字并追加省略号，中英文混排统一按字符数处理

**AC-4: 数据来源与文案国际化**
- **Given** 患者进入问诊记录区块
- **When** 系统加载并渲染列表
- **Then** 展示该患者真实全部问诊数据，且列表文案支持中英文切换，无写死中文
