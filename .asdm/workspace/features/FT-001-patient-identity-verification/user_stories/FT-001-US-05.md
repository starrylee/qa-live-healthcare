## 用户故事

```
作为一个 共用设备的患者，
我想要 退出当前身份切换到另一患者，
以便 多名患者共用同一设备时不串档，且各自档案持久保留。
```

## 验收标准（AC）

**AC-1: 退出仅清前端登录态**
- **Given** 当前已以某患者身份登录（持有其业务键/会话）
- **When** 点击「切换用户 / 退出」
- **Then** 系统清空前端 `currentPatient` 状态，页面返回身份验证表单

**AC-2: 档案持久保留可复用**
- **Given** 患者已退出当前身份
- **When** 再次以相同姓名+生日验证
- **Then** 命中同一档案与历史问诊，原档案持久保留不丢失
