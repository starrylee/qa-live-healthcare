## 用户故事

```
作为一个 患者，
我想要 凭姓名+出生日期完成身份验证并自动建立健康档案，
以便 无需注册即可问诊，并在再次访问时复用同一档案、查看历史问诊。
```

## 验收标准（AC）

**AC-1: 首次验证自动建档**
- **Given** 患者提交了系统中未匹配过的姓名+出生日期
- **When** 系统对姓名归一化后按 `normalizedName + birthday` 精确查重未命中
- **Then** 新建患者档案，生成 `PAT-` 业务键并持久化，返回 `isNew=true`

**AC-2: 已建档患者复用同一档案**
- **Given** 患者提交与历史建档一致的姓名+生日（允许大小写、首尾空格差异）
- **When** 系统归一化后查重命中已有档案
- **Then** 返回同一 `PAT-` 业务键，返回 `isNew=false`

**AC-3: 姓名录入容错**
- **Given** 患者姓名含首尾空格或大小写差异
- **When** 提交验证
- **Then** 系统执行 `trim`+`toLowerCase` 后正确命中或新建，验证成功率 100%

**AC-4: 参数校验**
- **Given** 姓名或生日缺失、或生日格式非 `YYYY-MM-DD`
- **When** 提交验证
- **Then** 系统返回 400

**AC-5: 并发防重复建档**
- **Given** 同名同生日的患者请求并发提交
- **When** 同时触发建档
- **Then** `(normalized_name, birthday)` 唯一索引/写入冲突回退查重保证仅产生一份档案与一个业务键
