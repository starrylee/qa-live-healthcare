## 用户故事

```
作为一个 已验证患者，
我想要 查看我的历史问诊记录，
以便 了解过往咨询问题与医生回复。
```

## 验收标准（AC）

**AC-1: 查询存在的历史问诊**
- **Given** 患者业务键名下存在由 `qa-service-question` 维护的问诊记录
- **When** 调用 `GET /api/questions?patientId=<业务键>`
- **Then** 返回 200，列表每项含 `id`/`patientId`/`doctorName`/`question`/`status`/`submitTime`/`answer`/`answerTime`

**AC-2: 查询无记录**
- **Given** 患者业务键名下暂无问诊记录
- **When** 调用 `GET /api/questions?patientId=<业务键>`
- **Then** 返回 200 与空列表，不报错

## 依赖关系

- 依赖于: 无（跨服务独立构建；数据通过 `patientId = PAT- 业务键` 关联，由 FT-001-US-01 产生的业务键标识）
- 被依赖: FT-001-US-04
