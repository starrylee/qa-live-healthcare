## 用户故事

```
作为一个 患者，
我想要 在前端通过真实后端接口完成验证建档并查看患者门户，
以便 体验与后端一致的数据，并能查看档案与历史问诊。
```

## 验收标准（AC）

**AC-1: 调用真实验证接口并区分首次/欢迎**
- **Given** 患者在前端身份验证表单提交姓名+生日
- **When** `Consultation.vue`/`store` 异步调用 `POST /api/patients/verify`
- **Then** 依据响应 `isNew` 区分展示「首次建档 / 欢迎回来」，进入患者门户

**AC-2: 门户展示档案与历史问诊**
- **Given** 验证成功进入患者门户
- **When** 门户渲染档案与「我的问题」历史区域
- **Then** 档案来自 `GET /api/patients/{businessKey}`、历史来自 `GET /api/questions?patientId=`，均正确渲染

**AC-3: 代理可达性**
- **Given** dev/prod 环境
- **When** 前端请求 `/api/patients`、`/api/questions`
- **Then** 经 Vite / Nginx 代理正确路由至对应后端（user/question 服务），请求不被拒
