## 用户故事

```
作为一个 已验证患者，
我想要 查询我的健康档案信息，
以便 在患者门户中查看身份与建档信息，并供前端校验。
```

## 验收标准（AC）

**AC-1: 查询存在的档案**
- **Given** 传入的业务键对应档案存在于 MySQL
- **When** 调用 `GET /api/patients/{businessKey}`
- **Then** 返回 200，响应包含 `businessKey`/`name`/`birthday`

**AC-2: 查询不存在的档案**
- **Given** 传入的业务键在系统中不存在
- **When** 调用 `GET /api/patients/{businessKey}`
- **Then** 系统返回 404
